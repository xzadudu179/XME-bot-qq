Tutorial · AI Helper

AI 助手，
十分钟上手。

/ai 是漠月体内那只更爱说话的小模型：能聊天、查资料、写代码、生成图片， 还能把会话变成多人共享的房间。以下六步，带你把它玩明白。

Ask · Explore · Create
STEP 01

第一次交谈

和它打招呼，就这么简单：

❯ /ai 你好！简单介绍一下你自己吧~

也可以直接抛问题：「今天杭州天气怎么样」「帮我写一段 Python 冒泡排序」。群里喊一声「漠月」或 @TA 再接内容，同样能唤起对话。

STEP 02

让它替你干活

它最擅长三件事：联网查资料、写代码（推荐网页三件套 HTML / CSS / JS）、AI 生图。想要多花的图片就多说细节——TA 可能会超常发挥（？）

❯ /ai 用 three.js 写一个旋转的十二面体 demo
❯ /ai 画一张「沙漠夜空下的月亮」概念图，橙色主色调
✓ 图片已生成 >>（一张图 80,000 credits）
STEP 03

模型档位与额度

flash · 默认档 —— 快而实惠，日常首选
pro · -m pro —— 更聪明也更贵（消耗 ×10）
❯ /ai -m pro 把上一条代码重构得更优雅

每日额度 6,000,000 credits；命中缓存的回复按 ¼ 价计费，读图、OCR 也折算消耗。额度按天重置。

STEP 04

会话收纳术

AI 的记忆按会话独立保存。把控制参数放进任意一句话即可生效：

-c new 新建并切换会话
-c list 查看全部会话（含序号）
-c swi 2 切到 2 号会话
-c name 2 项目 给会话重命名
-c clear 清空当前会话记忆
-c history 回看最近 30 条
STEP 05

开房间：共享会话

把会话变成多人房间，凭房码加入，全员同屏——很适合群友一起调教小 AI：

❯ /ai -c share   → 房间已创建，房码 AI0721
❯ /ai -c join AI0721   → 申请已发送，等待群主审批
❯ /ai -c kick 2   → 已移出捣乱成员（群主专用）
❯ /ai -c leave   → 悄悄退场
STEP 06

紧急制动与小抄

aistop 对话进行中随时喊停
-r raw 参数总被误判？用它包住纯文本
幻觉提醒 重要事实请二次确认（玩梗除外）
-c clear 说怪话时的疗方：清空记忆

生成的答案仅供参考——TA 的想象力时常大于事实，但这也是它可爱的地方。

FAQ

几个常见疑问。

credit 是什么？怎么计算的？

按模型消耗的 token 计费：flash 为基准价，pro ×10，读图按 80,000 credits/张折算，命中缓存 0.25×。每日总额度 6,000,000，按天重置。

它说的话可以全信吗？

不可以。它充满想象力，重要内容务必自己复核；但让它「假装」或玩梗的时候，永远可以期待惊喜。

会话记录保存在哪？隐私怎么处理？

记录按账号隔离存储。使用 -c clear 清除当前会话，-c clear-all 清除并删除全部会话——删掉的东西就真的没有了。

参数总是被误解析怎么办？

在消息开头加 -r，之后的全部文本都会被当成纯文本处理。
