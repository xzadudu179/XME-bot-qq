02 — Get Started

三步，开始。

STEP 01

邀请入群

把 Deon 拉进你的群，和群里的管理打好招呼。想请走的时候一句 /bot_leave 就够，别禁言它——容易触发风控的。

STEP 02

发送指令

以 ○ . 。 / 任一前缀皆可唤醒：/sign 打卡、/weather 看天、/lot 试手气。加前缀写 TA 的名字也一样有效。

STEP 03

出发探海

敲下 /seek，随洋流进入 SeekerOS。温馨提示：海面之上阳光明媚，海面之下未必。

把月亮，拉进你的群。
