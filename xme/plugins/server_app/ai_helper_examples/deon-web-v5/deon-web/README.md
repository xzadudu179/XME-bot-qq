# 漠月 Deon · XME-Bot 官网 / SeekerOS

一只来自沙漠星球的小狗机器人（Deon / 漠月）的介绍站，
包含「SeekerOS · 无尽之海」实时 3D 海面页。

## 目录结构

```
deon-web/
├── index.html        首页（hero + 功能矩阵 + 快速开始 + CTA）
├── commands.html     指令手册（分类列表 + 关键词过滤）
├── tutorial.html     AI 助手 /ai 六步上手教程
├── seekeros.html     无尽之海入口页（Three.js WebGL 海面）
├── css/
│   └── main.css      全站设计令牌与共享基元（含 SeekerOS HUD/卡片）
└── js/
    ├── site.js       公共交互：昼夜主题引导切换 / 移动端菜单 / 入场动画
    └── ocean.js      SeekerOS 海洋场景（Gerstner 波·折射 RT·菲涅尔·
                       glitter·焦散·泡沫·暗流触手·光柱·荧光尘埃·
                       漂流瓶状态机）
```

## 运行

无构建步骤。因为浏览器对 `file://` 下的模块/资源加载较严格，
建议任选其一：

```bash
# python
python -m http.server 8000          # 然后访问 http://localhost:8000

# node
npx serve .
```

或直接托管到任意静态服务器（GitHub Pages / Vercel / Nginx…）。

外部依赖（均为 CDN，可替换为本地文件）：
- three.js r128 — SeekerOS 场景
- Tailwind Play CDN — 首页/指令页排版工具类
- Google Fonts — Space Grotesk / Noto Serif SC / Noto Sans SC

## SeekerOS 页要点

- 双 pass 渲染：先渲染水下世界到折射 RT，再绘制天空+水面，
  水面片元按波法线扰动采样 RT 得到扭曲的水下影像。
- 昼夜海况与站点主题联动：右上 ◐ 一键切换；也可用
  `seekeros.html#night` / `#day` 强制指定，`?auto=1` 跳过入场。
- 漂流瓶：自动漂入 → 停驻 60s（HUD 显示自沉倒计时）→ 点击
  读信（阅读时暂停倒计时）→ 关闭后漂走淡出，随机再来一瓶。
- 性能：移动端自动降低几何段数与实体数量；帧时超标自动降 DPR。

## 设计约定

- 强调色仅使用橙色一族（light `#cc4b06` / dark `#ff7c2d`）。
- 排版采用编辑式语言：细线分栏、超大衬线标题、等宽注记，
  不堆砌卡片与圆角矩形；hover 克制。

### 调试参数
- `seekeros.html?fast=1`   漂流瓶约 2.5s 即出现且复活间隔缩短（调参/演示用）
- `seekeros.html?auto=1`   跳过入场遮罩自动下潜
- `seekeros.html#night`    强制夜海；`#day` 强制昼海
- 昼海/夜海预览样张见 `preview/` 目录（含基址修正与强制参数，供离线截图复核使用）

### 已知验证局限
本次预览沙箱不执行 JS 与 Tailwind CDN 运行时，动态效果（海面渲染、瓶漂移动画、菜单/FAQ 过渡、marquee 克隆）
无法在离线截图中闭环呈现；已用静态层完成桌面双栏/三列网格、导航与列表节奏的视觉审校，
建议本地起服务后各页走查一遍，尤其是 SeekerOS 的昼夜海况与拖拽视角手感。
