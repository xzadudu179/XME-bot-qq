漂流瓶与 SeekerOS

4
/throw
扔瓶子

把一段话（可附图）封进玻璃瓶扔回大海，等待某个陌生人捞起它。

扔漂流瓶 · 扔瓶
/pickup
捡瓶子

从海里捞起一只瓶子。深夜的海不太平静……可能会捞到「别的东西」。发现违规内容回复 -rep 举报。

pick · p · 捡漂流瓶
/seek
无尽之海寻宝

意识上传 SeekerOS，随洋流向海底无尽下沉。深度单位是 d.n.，不是米。本站的 SEEKEROS 页面就是它的门户预览。

sk · 寻宝
/custom
皮肤定制

在商店购入皮肤后，在这里设置你的漂流瓶卡片样式。

cus · 自定义
